# VenasFoldSpectrum 首版规格

定稿：2026-11-18。首版供用户在 OPPO Find N6 自用测试。正式设计稿到来前按会话草稿确定功能及布局；动效、手势反馈、排版参考 apple-design，使用原生 Android / Kotlin / Jetpack Compose 实现。

## 范围与项目

- 独立项目，应用名 VenasFoldSpectrum，包名 `com.venas.foldspectrum`。
- 参考目录 `../LinzinDeskClock-main` 保持原样。仅参考折叠阈值、厂商外屏状态映射、生命周期复原及防烧屏思路，业务与界面独立实现。
- 不限定播放器。网易云音乐与 Poweramp 是首批必测对象，其他播放器通过标准媒体会话接入。按单一音源播放场景设计。
- 不使用每次新会话都需要确认的 MediaProjection。仅从真实系统输出采样，不补造频谱、实时波形或测量数值。
- 网易云音乐／Poweramp × 手机扬声器／蓝牙四种组合都必须实测。任意组合无法工作即为验收阻塞项；呈现正确失败状态不等于该组合通过。

## 初始页设置与普通手机

- 11月23日追加音量调整和防烧屏模式，共六项设置，初始页与可视化面板共用。音量滑条控制系统媒体音量STREAM_MUSIC，按当前输出的最小/最大档位调整；面板存在时每500ms只读同步，仅用户操作滑条才写入，不保存重放旧音量。固定音量输出禁用，系统拒绝时提示。
- 防烧屏开关默认开启且持久化，仅开关可点击。关闭立即取消遮罩，重新开启、关闭设置面板后重新计时；设置打开期间不启用遮罩。Android12禁用并说明需要Android13。无触摸1分钟启用、每5分钟交替，画面变暗但不改系统亮度，不进行微移。

- 初始页用一个圆角矩形“展开设置”按钮展开四项设置，再次点击“收起设置”折叠面板：旋转180°、非折叠模式、屏幕常亮、界面亮度。前两项默认关闭，常亮默认开启，亮度默认跟随系统。各设置持久化，保留已有flip和nonFoldMode选择，不在更新时重置。
- 旋转180°关闭时沿用帐篷默认横屏方向，开启反转，用于背板朝下等相反摆位。非折叠模式也共用此设置；窗口固定REVERSE_LANDSCAPE，开启时应用内容与设置对话框一起旋转180°，触摸坐标同步转换，不依赖系统是否接受相反横屏请求。准备页不翻转。
- 非折叠模式开启：使用当前屏幕，忽略转轴和厂商外屏请求。权限齐全后，物理横放进入可视化/无媒体时钟，竖起稳定400ms自动返回准备页（用户已确认）。准备页提示“请将手机横放，以显示音频可视化”。
- 物理姿态来自OrientationEventListener，不由已经锁定的窗口宽高推断。自然竖屏设备的横向进入区为60°–120°及240°–300°；竖向退出区为0°±30°或180°±30°。中间角度和不可判定姿态保持现状。天然横屏面板按实际长边换算。重新启用监听获取新首帧，不依赖用户再移动手机。
- 非折叠模式返回键退出后，保持准备页直到竖起再横放或重新打开；后台停止方向监听。两模式切换清理旧请求/监听，既有媒体与音频逻辑共用。
- 屏幕常亮开启时，只在可视化/时钟前台设置KEEP_SCREEN_ON，覆盖系统自动息屏计时；手动锁屏仍有效。关闭、回准备页或离开应用后使用系统息屏行为。
- 四行均只有右侧Switch可切换，点击名称、说明和行内空白不触发；滑杆保持直接拖动。
- 界面亮度开关关闭时跟随系统，开启后手动10%～100%，手动默认值50%。滑杆实时预览，松手、关闭设置或退后台保存。仅设置Activity及设置对话框的窗口亮度；不改全局亮度、不申请写系统设置权限，离开应用后其他窗口照常使用自己的亮度策略。
- 可视化页单击封面/进度区以外区域后，右上角显示48dp触摸区域、16dp可见调节图标；可见右边缘对齐PLAYING最右侧。图标与状态文字以180ms透明度交叉过渡，3秒未点击自动淡出；重复单击续期。已按住按钮时保留到抬起，避免在触发瞬间移除。时钟页也可呼出，并提供无障碍“打开设置”操作。
- 点击图标打开可滚动设置对话框，四项控件与初始页共用；点击“完成”或系统返回关闭。对话框阻止触摸穿透，底层可视化保持组合状态，不因打开设置重新建立封面/拖动状态，也不暂停播放。

- 初始页设置区域下方、调试信息上方显示居中双图标，左GitHub链接`https://github.com/VERSTA233/VENAS-fold-spectrum`，右bilibili链接`https://space.bilibili.com/34241475`（逆星朔影）；通过浏览器打开。图标24dp、触摸区48dp。

## 折叠与生命周期（非折叠模式关闭时）

- 用户手动打开应用，通知使用权与音频权限齐全后，转轴10°–150°自动请求外屏。外屏指令成功后显示桌面页并固定横屏；不检测桌面倾斜、重力方向或“平放”。超过165°或闭合至5°及以下持续400ms才退出，中间角度保持当前状态。
- 已经摆好帐篷再启动时，若转轴传感器尚未给出首个事件，应用以自身UID读取系统物理姿态。Base state为TENT时可进入；无软件覆盖时允许用Committed state的TENT。已有软件覆盖时不能用它冒充物理状态。取得实际角度后恢复角度规则，不要求先抬起手机。
- 保留厂商映射：HONOR 4；Google 3；Samsung/OPPO/OnePlus/vivo 1；Xiaomi 0；其他3。状态值必须以各设备实测为准。
- 外屏固定横屏，沿用大折叠默认反向横屏，内屏提供“旋转180°”开关。
- 展开后回内屏准备页，音乐播放不受影响。
- Home／切换应用后连续后台1500ms才退出外屏、释放状态覆盖和音频读取资源，不暂停音乐。宽限期也覆盖进入外屏之后的旋转，不再在onUserLeaveHint中立即清空桌面状态；恢复前台和显示配置变化时重新核对折叠条件。
- 系统返回立即退出。返回键退出后，同一进入角度区间内不立即重新进入；离开10°–150°区间或重新打开应用可解除抑制。外屏命令失败时显示错误与重试入口，不能假设已切到外屏。
- 外屏是否保持常亮遵循设置，默认开启；离开时恢复系统息屏行为。
- 闲置1分钟后启用棋盘像素遮罩，每5分钟交替，触摸后取消并重新计时。按用户要求移除±1像素位移，画面位置固定。遮罩需要Android 13及以上，Android 12不应用此效果。

## 准备页与权限

- 上方：封面、曲名、艺人名。下方：“请半折手机，以在外屏显示可视化”。
- 无歌曲：默认封面和“未检测到正在播放的音频”。有歌曲但缺封面：默认封面，其余照常。
- 首次使用说明通知使用权和系统显示为麦克风／录音的 RECORD_AUDIO 权限用途。不录制麦克风，不保存音频。
- 拒绝后只保留缺失权限说明及手动入口，不循环弹窗。
- 权限未齐留在准备页。折叠模式权限齐全且仍半折时自动进入外屏；非折叠模式须物理横放。

## 外屏内容

- 左侧：封面、曲名、艺人名；曲名和艺人名相对封面左边缘稍向右缩进。右侧：频谱、播放进度图、底部三个模块。屏幕左侧到封面、封面到右侧信息区、信息区到屏幕右侧三处间距相等；常规横屏均为屏宽8%，阔屏尺寸分支均为4%；左侧文字限制在封面宽度内。
- 阔屏适配仅在实际窗口宽高比1.20～1.60（含边界）启用，其他尺寸沿用常规布局，不更改半折检测。阔屏封面为min(屏高52%,屏宽35%)；u=min(屏高dp/410,屏宽dp/580)，限0.5～1.35。常规仍为min(屏高57%,屏宽27%)，u仅按高度并限0.65～1.35。
- 播放状态的封面槽位顶部固定，与SPECTRUM标题上缘对齐；曲名一行或两行都不移动封面。暂停时仅封面以中心为锚点平滑缩到原宽高75%，恢复到100%。文字保留固定位置；恢复此前紧凑的16u/5u布局间隔，不保留拉大至32u的尝试，也不强求艺人名与波形底边对齐。
- 曲名21u sp、固定行高26u sp；艺人15u sp、固定行高20u sp。中文恢复原字号，英文与中文均不缩放字形。曲目文字使用原生TextView，关闭额外字体padding与fallbackLineSpacing，以SF Pro参考基线及显式LineHeightSpan固定行度量，思源黑体回退不再撑高文本框。准备页同步。保留原生混排、换行、省略及无障碍。同样行数保持相同文字位置，实际两行标题增加一行并让艺人下移；16u/5u间距不变。
- 曲目封面按曲目身份与有图/无图区分过渡，同曲播放状态刷新或重复回传Bitmap不触发淡出。默认封面为独立矢量资源`res/drawable/album_placeholder.xml`。
- 横滑时对当前封面的圆角形状与图片一起做四角透视投影，远侧边的高度随角度缩短。取消未提交的拖动回到当前位置；已提交切歌的封面只继续离场。每次翻页持有独立快照和动画，连续操作不复用最早的旧封面；最多保留3个离场层。新封面无预加载要求，到达后淡入并从96%轻微放大；缺图先显示占位。系统关闭动画时省略空间变换。
- 频谱：真实FFT数据，横轴20/200/500/1k/2k/4k/8k/16k；采样绘制范围仍到20k或奈奎斯特频率。每个实际FFT频点只归属一根柱，低频不复用频点；所有柱等宽，轴标签按柱子的实际频率边界定位，低频间距相应压缩。
- 纵轴0/−15/−30/−45/−60及对应网格，数字统一右对齐；绘制底线为−60。纵轴是固定参考的相对幅值刻度，不宣传为校准仪表；低于−60的值不显示。Visualizer输出为8位有符号FFT：实部和虚部都在−1～1的频点视为最低一级量化不确定值，在每组取最大值之前排除，避免约−42.1的假底座。规则一致应用于所有频率；高于该级的数据不减值，不单独压低高频。该处理也会隐藏落在同一量化级的极弱真实分量，不能将空白解释为频段能量严格为零。
- 频谱保留原先快速过渡：上升100ms、回落200ms指数平滑，播放时不提前吸附至目标。只对真实采样做过渡，不补造频谱内容。用户明确否决通过加大阻尼消除停顿，因为会牺牲动态；Find N6蓝牙停顿采用独立的采样时序兼容处理，见下文。
- 进度图：规则重复几何刻度，一眼可辨为设计图形；不是整首歌真实波形。
- 左侧0:00，右侧总时长，与白底黑字当前时间标签处在同一水平线上；当前时间标签位于最上层，经过两端时可直接覆盖起点／终点时间。红线表示真实进度，时间标签紧邻红线上方并保持在屏内。进度区域紧凑；白色时间标签和进度条作为整体在两条横线之间垂直居中，不再要求刻度条自身上下等距。
- 无有效总时长：进度图整体替换成“无可用进度信息”，不显示任何时间、红线或拖动行为。
- 底部使用三栏信息条：常规比例2:1:1，阔屏比例1.25:1:1。常规左侧约一半宽度显示 WAVEFORM 标签与无边框实时竖线波形；中间 LEVEL，RMS dBFS；右侧 DYNAMIC，短时峰值与平均电平之差，单位dB。三栏标签同排，波形与数值区垂直对齐，数值与单位基线对齐，以两条淡竖线分区。无 SAMPLE RATE、PEAK 或 LUFS 模块。WAVEFORM 只在绘制前施加固定3倍显示增益并限制到绘图区；不自动归一化、不改变LEVEL/DYNAMIC计算，静音仍为空。播放恢复35ms快速指数响应，暂停90ms回落，播放时不提前吸附目标；不保留慢阻尼实验。
- 初始计算口径：LEVEL用Android Visualizer测量的RMS；DYNAMIC取近1秒测量数据的最高峰值减去RMS能量平均（峰均差，不是整首歌DR/LRA）。测量接口不支持时显示 `—`。
- 阔屏底栏内边距6u dp、数值18u sp、单位8u sp，数值和单位字距0；常规仍为14u dp、20u/8.5u sp及原字距。只调整显示尺寸，不影响测量与刷新。
- LEVEL和DYNAMIC作为一对数值每500ms发布一次（由其后的第一帧采样驱动）；内部测量与一秒峰均差窗口继续按采样频率计算。暂停／不支持立即显示 `—`，新曲和恢复播放清除旧测量，首帧可立即刷新。频谱和WAVEFORM不受这个数字刷新间隔限制。
- 英文状态／仪表标签，简体中文说明及错误信息。
- 右侧数字与英文统一使用用户提供的 SF Mono 等宽字体，采用斜杠零；包含频率／幅值刻度、进度时间、状态、LEVEL／DYNAMIC 与单位。标签中等字重、标题稍重，数值与单位基线对齐。用户已确认参考图字体并提供本地字体文件。
- 封面下曲名／艺人名：使用用户在 `Font/` 提供的 SF Pro 与思源黑体 SC Regular；Android原生字形回退链先SF Pro、再思源黑体、最后系统通用回退，英文／中文混排在同一个文本段落内测量、换行和省略。准备页的曲名／艺人名也使用相同字体。

## 状态与切换

| 状态 | 右上角 | 频谱和实时波形 | 其他内容 |
| --- | --- | --- | --- |
| 播放且采样正常 | 红点 PLAYING | 使用真实音频 | 元数据和进度正常更新 |
| 暂停 | 暗色 PAUSED | 逐渐回落为空白 | 保留歌曲和进度 |
| 切歌／缓冲 | LOADING | 平缓回落，无文字提示 | 等待新曲 |
| 确认捕获失败 | UNSUPPORTED | 停止；频谱区“当前音频源不支持实时可视化” | 保留封面、曲名、进度；LEVEL/DYNAMIC为 `—` |
| 无媒体会话 | 极简时钟 | 无 | 24小时HH:mm，无秒／日期；下方“播放音乐可显示音频可视化” |

- 切歌间隙和音频静音不是不支持的证据。只将明确的初始化／采样接口错误或无回调视为捕获失败。全零的正常回调不能证明支持，也不能仅凭其断言不支持；须用真实有声曲目验证。
- 极简时钟使用内置SF Mono Regular，目标字号144sp（原108sp）、行高160sp、字距0；根据实际字体测量及可用宽高缩小以完整显示。HH:mm本身居中，提示文字位于时间文本框下方14dp，不将时间向上挤。
- 时钟检测到播放后自动切换。已有曲目暂停则保留 PAUSED 页面。
- 暂停直接释放Visualizer，恢复重新建立；初始化、释放、新曲时清空待显示数据。先前1500ms保留实例的尝试没有解决同步停顿，已在11月20日最终清理中移除。有效的蓝牙修正保留在AudioCapture中。
- 蓝牙兼容：仅OPPO PLP110/API37且系统媒体路由全部为A2DP时，绕过Visualizer的延迟回读，改为采集线程按系统输出延迟暂存并发布真实分析帧。本轮读到369ms，用户确认连续且节奏基本对齐。波形/FFT/数值同批延后，不减慢绘制响应；新曲、重新采集、释放/失败清空队列。扬声器或混合输出保持标准路径；每秒核对媒体路由，切换后重建并重新估计延迟；同一路由的输出延迟也持续核对，显著变化时整体重新定时待显示帧。兼容API不可用则保留标准采集，不把无补偿的抢拍版本作为回退。详见[蓝牙修正说明](BLUETOOTH_CAPTURE.md)。
- 会话消失后等约3秒再回时钟，避免临时重连闪屏。
- 自动选择正在播放的播放器，全部暂停时保留最近使用的播放器。选择对象同时用于元数据和控制；音频来自系统输出混音，首版按单音源场景验收。

## 手势

- 仅单击专辑封面：播放／暂停。抬起提交，播放状态驱动封面缩放；按下不额外变暗或替换图片层，滑动不误触单击。曲名、艺人名、频谱、指标和空白区域不触发播放控制，进度区域单击也不切换播放。
- 仅从专辑封面开始的横向滑动：右向左下一首、左向右上一首。手势归属由首次按下位置确定，从其他区域滑入封面不切歌，从封面开始后可以继续拖到封面外。无障碍播放／切歌操作也限定在封面节点。
- 封面/进度区以外单击只呼出设置入口；从这些区域起手滑动不切歌、不呼出设置。设置按钮自身消费触摸，不向底层手势传递。
- 进度区域横向拖动优先移动红线，不切歌。实时预览目标时间，松手才发出跳转请求。
- 每次按下从屏幕上当前显示的红线位置开始，保留手指与红线之间的偏移；连续拖动沿用最近的预览／待确认位置，不回退到播放器旧进度。绘制与拖动使用同一刻度宽度。
- 播放器回传确认前保留最新跳转目标，播放中按目标时间继续推算；暂停时保持目标不动。旧会话、旧曲目、较早跳转结果及元数据刷新不覆盖当前拖动。超过6秒仍未确认时提示“播放器未确认跳转，已恢复实际进度”，避免静默回跳；正在拖动时不触发上一请求的超时。
- 暂停时跳转仍保持暂停。为应对 ColorOS 冻结暂停播放器导致延迟处理，松手时先向当前会话发送明确的 MEDIA_PAUSE 按键，再提交一次标准 seekTo；不会先恢复播放。没有有效时长或播放器不支持seek时不发送跳转。
- 支持Android系统返回。播放器未支持某控制操作时提示，不伪造成功。
